# Support for THOTH

## Documentation and ordinary questions

Start with the [user documentation](https://textailes.github.io/thoth-documentation/) and [deployment guide](docs/DEPLOYMENT.md). THOTH supports native ATON, PM2-managed native deployment, local Docker, and HESTIA Docker. HESTIA requires external services and identity configuration described in the deployment guide.

For a reproducible problem, open a [bug report](https://github.com/TEXTaiLES/thoth/issues/new?template=bug_report.yml). For an improvement, open a [feature request](https://github.com/TEXTaiLES/thoth/issues/new?template=feature_request.yml). For a question that the documentation does not answer, a blank issue is acceptable. Include the workflow and environment, and say which documentation you consulted. You may write “unknown” for technical details you cannot identify.

## Self-hosted installations

Self-hosted installation operators are responsible for their own configuration, credentials, backups, and service operations.

## Expectations and maintenance

Support, review, and development depend on maintainer capacity and project resources. Response times, resolution dates, and implementation of feature requests are not guaranteed. No fixed period of post-project maintenance or future feature development is promised here.

## Sensitive reports

GitHub issues, pull requests, and their attachments are public. Do not post credentials, session cookies, personal data, confidential information, or restricted collection material. Do not publish vulnerability details or conduct complaints as ordinary issues.
